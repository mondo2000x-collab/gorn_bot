# ГОРН — бот и приём заявок (Vercel)

Две функции в одном проекте:
- `api/webhook.js` — Telegram-бот (меню, калькулятор покраски, сбор заявок на изготовление)
- `api/lead.js` — endpoint для формы на сайте (шлёт заявку в Telegram + на почту)

## 1. Деплой на Vercel

1. Залить эту папку в отдельный репозиторий на GitHub (например `gorn-bot`)
2. На vercel.com → **Add New Project** → выбрать репозиторий
3. В **Settings → Environment Variables** добавить:
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather
   - `MANAGER_CHAT_ID` — `6471763104`
   - `RESEND_API_KEY` — (опционально, см. п.3)
   - `LEAD_EMAIL_TO` — `an.yurev20007@gmail.com`
4. Нажать Deploy. После деплоя получите адрес вида `https://gorn-bot.vercel.app`

## 2. Подключить бота к вебхуку

Выполните один раз в браузере (подставьте свой токен и домен):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://gorn-bot.vercel.app/api/webhook
```

Должно вернуться `{"ok":true,"result":true}`. Дальше бот сам отвечает на сообщения — напишите ему `/start`.

## 3. Почта (необязательно)

Если хотите, чтобы заявки дублировались на email:
1. Зарегистрируйтесь на resend.com (бесплатный тариф — 100 писем/день)
2. Получите API key, добавьте его в переменную `RESEND_API_KEY` на Vercel
3. Пока ключа нет — бот и форма работают нормально, просто без писем

## 4. Форма на сайте (FirstVDS)

На сайте форма должна отправлять POST-запрос на ваш Vercel-адрес:

```js
fetch('https://gorn-bot.vercel.app/api/lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name: 'Иван',
    phone: '+7 999 000-00-00',
    service: 'Порошковая покраска',
    message: 'Комментарий клиента'
  })
});
```

CORS уже разрешён в коде (`api/lead.js`), так что кросс-доменный запрос с FirstVDS на Vercel пройдёт без прокси на nginx — отдельно настраивать `proxy_pass` для этого не обязательно.
